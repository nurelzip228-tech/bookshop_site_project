УЧЕБНЫЙ ПРОЕКТ: КНИЖНЫЙ МАГАЗИН «ЛИСТ»

Как открыть:
1. Распакуй ZIP-архив.
2. В VS Code выбери File → Open Folder.
3. Открой папку bookshop_site_project.
4. Открой index.html в браузере двойным нажатием в Проводнике.

Структура:
- index.html — содержание и структура страницы.
- css/style.css — цвета, размеры, шрифты и расположение.
- js/script.js — мобильное меню.
- images — папка для изображений (пока не используется).

Что попробовать изменить:
- В index.html найди «ЛИСТ» и поменяй название магазина.
- Найди названия разделов книг и измени их.
- В css/style.css найди переменные в :root и попробуй изменить --green или --orange.
- Сохраняй изменения (Ctrl + S), затем обновляй страницу (F5).

Важно:
Адрес, телефон и время работы на странице вымышленные — это учебные данные.
Шрифты загружаются из Google Fonts, поэтому для них нужен интернет.
